# Synthetic task run checklist

## Purpose and intended use

For a planned run, record the task-file version, condition labels, response
mapping, missing-response rule, output location, and reviewer.

## Guidance or reference

A real project would link its approved task specification and protocol.
This exemplar supplies neither.

## Applicability and limits

Checking this list does not establish that a task was delivered correctly or
that collected data are valid.
