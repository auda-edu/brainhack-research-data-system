# Synthetic resting-state QC worksheet

## Purpose and intended use

For each planned processing run, record the input version, software and
settings, checks performed, outputs, and the reviewer. This is a documentation
prompt, not a validated imaging protocol.

## Guidance or reference

A real record would point to the lab-approved protocol and its version.
No such protocol is supplied in this fictional example.

## Applicability and limits

The worksheet does not establish image quality or reproducibility by itself.
