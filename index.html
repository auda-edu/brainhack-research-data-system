A research memory layer for the lab.
Existing tools can organize, process, publish, and discover data. The missing layer is often the history needed to understand why a project looks the way it does—and how to restart it.

Lifecycle ≠ access

Active, dormant, restartable and archived are independent from public, internal and restricted.

Files ≠ memory

Code and data rarely explain decisions, failed analyses, ownership, caveats or the best restart point.

Don't rebuild FAIR tools

Connect Nipoppy, DataLad, Neurobagel, repositories and ELNs instead of replacing them.

Labhippo asks: can institutional research memory become structured, searchable, maintainable—and useful to both humans and AI?

Brainhack MVP

Test whether “lab memory” can be made operational

1
Define the smallest memory schemaProject ID, lifecycle, access, people, storage references, decisions, known issues, restart state.
2
Bridge—not duplicate—existing metadataImport/reference Nipoppy status, Git commits, DataLad IDs and publication links.
3
Capture one provenance storyDataset/version → processing → code → analysis → figure, plus the decision that changed it.
4
Generate one living project siteAutomatically expose state, history, owners, known issues and restart instructions.
5
Ask it through Discord“Why did this change?”, “Which data made Figure 2?”, “Can I restart this project?” → answer + sources.

Questions worth hacking on

  • What information is genuinely missing from Nipoppy/Neurobagel/DataLad?
  • What must be recorded before a project becomes dormant?
  • How do we capture decisions without creating documentation burden?
  • Should provenance be stored per dataset, analysis run, artifact—or linked across all three?
  • How can restricted metadata be searchable without leaking participant information?
  • Who owns maintenance when students leave and projects sleep for years?
  • Can AI reliably answer from structured memory without becoming the source of truth?
MVP success: a new member can understand one dormant project and restart one analysis without finding the original analyst.
Goal: prototype the connective memory layer, not another research platform.3 / 3
