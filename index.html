Install and offline limits

On a supported HTTPS host, use Chrome's Install app menu, or Safari on iPhone: Share, then Add to Home Screen. Browser support varies; installing may not show a button. This is a browser app. A native mobile companion is a later milestone.

03 / EXPLORE · FICTIONAL DATA

Follow the record.

Search two invented projects, their decisions, resources, and daily logs. Open a record to trace its links and original Markdown. Nothing here represents real research.

Local demo workspace · export / import

Save fictional records from Capture, then search them here. Storage is specific to this browser and site origin, is unencrypted, and may be cleared by the browser. Other scripts on this origin can access it. Preview URLs on the same origin share this workspace; another device or origin does not. No sync or backup is provided. Never store real research records, participant details, or secrets.

JSON exports contain complete demo Markdown and retained revisions. Keep them as your backup; import a version 1 or 2 demo workspace with all its referenced local records. Identical records are kept once; conflicting IDs, paths or revision histories reject the entire import.

Checking browser storage…

Local drafts / revisions / reversible archive

Editing keeps the stable ID and path. Archive hides a draft while retaining its Markdown and history; Restore or Undo makes it recoverable. Active relationships must still resolve. Built-in examples cannot be changed.

The first explicit lifecycle change writes workspace version 2. Reading an existing version 1 workspace does not migrate it. Revision times come from this browser and are not a trusted audit trail. Keep exports; close older app versions before editing.

Saved storage needs recovery

The original text is preserved. Download it first, inspect or repair it outside this app, and keep that file. Explicit recovery retains another raw copy in this browser before creating an empty workspace. Nothing is silently reset.
