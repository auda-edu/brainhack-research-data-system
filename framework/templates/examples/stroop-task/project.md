# Synthetic Stroop task experiment

This entire record is fictional. No person completed a task and no behavioral
data or study findings exist behind this example.

## Research question and scope

How would the team document its task design, trial labels, response recording,
and review steps before a real experiment? The example does not estimate a
Stroop effect.

## Objectives

Record the proposed task version, condition labels, response rules, and
planned summary outputs. Log later deviations as separate project events.

## Current state and next action

Planning only. The example experiment lead will draft a task specification
and obtain review before any real use.
