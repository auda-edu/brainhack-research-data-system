01 / SYSTEM BOUNDARIES

The context layer.
The data stays accountable.

Bring projects, research activity and evidence into one view. Keep each source system responsible for the information it owns.

A

Know the owner.

A catalog reference is distinct from the notebook entry, stored bytes and execution evidence it describes.

B

Pin the version.

Trace a reviewed result to exact inputs, code, parameters and outputs. A moving folder or branch cannot define a reproducible result.

C

Release deliberately.

Internal access and public export are separate decisions. Review a specific artifact version before releasing it.

THE REVIEW QUESTION

Which exact data and code produced this result?

Select a node to inspect its owner, frozen version or execution evidence. Working assets stay separate from frozen DatasetVersions.

Completion can be reopened. History stays.

Invented lifecycle events. Completing a project neither freezes every file nor publishes its results.

    Evidence has limits.

    Checksums identify bytes; they do not prove ethical approval or scientific validity. A successful HPC exit status and a Git commit do not approve a result. This fixture contains invented version pins, not evidence of a real execution.

    04 / ACCESS & RELEASE

    Research access.
    A separate release decision.

    These are proposed policy requirements, not live permissions. All values in this static prototype are public synthetic examples.

    Release review examples

    A local checklist illustrates why approval must bind the exact version and audience. It performs no publication or security enforcement.

    Public output is a new artifact.

    1. Resolve the selected result and its required evidence versions.
    2. Review fields, derived files and linked identifiers for the intended audience.
    3. Bind the approval to a release manifest, artifact digest and policy version.
    4. Build isolated public output and review every index, source map, image and download.
    5. Record publication and support a reviewed withdrawal or superseding release.
